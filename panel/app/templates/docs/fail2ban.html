What it does

Anything on the internet that listens on SSH is constantly probed by bots guessing passwords. Fail2ban watches the login log and, when one IP fails too many times, blocks it at the firewall for a while. The Fail2ban page installs and manages it.

Installing

Click Install. SSH protection is switched on with the recommended settings, and your current IP is added to the never-ban list automatically so a mistyped password cannot lock you out. The panel verifies after installing that the protection can actually block (if a rule could not be attached, the page shows a warning and a Repair button).

How banning works

With the defaults, when an IP fails 5 times within 10 minutes it is blocked from SSH for 1 hour. With growing bans on, every repeat offence doubles the ban, up to a maximum of 1 week. The SSH port is detected automatically, so if you move SSH to another port just save the settings here again.

Settings

SettingMeaning
Failed attempts before a banHow many failures trigger a ban (default 5).
…within this time windowThe period those failures must fall in (default 10 minutes).
Ban lengthHow long a ban lasts (default 1 hour).
Growing bansDouble the ban each time the same IP returns.
Longest a growing ban can getThe cap (default 1 week).
Never ban these IPsTrusted addresses: yours, your office, monitoring. Add one per line.
RecidiveOptionally ban repeat offenders for 1 week on every port, not just SSH.

Changes are checked with fail2ban's own test before they are applied, and rolled back if they would break it.

Status and banned IPs

The page shows whether fail2ban is running, total failed attempts and bans, and every IP blocked right now with when the ban expires.

  • Unban lifts every ban on an address (useful if a colleague got blocked).
  • Ban an IP manually blocks it from SSH for the ban length, or choose Permanent to block it on all ports forever. Permanent bans are stored by the panel and re-applied if fail2ban's own state is ever lost.

Repair

If the page says fail2ban is "detecting attacks but not blocking them", a jail has no block action. Repair restarts fail2ban to fix this; existing bans are restored.

The stronger fix: SSH keys Fail2ban slows attackers but attacks spread over many IPs each get their own attempts. Adding your SSH key and then disabling SSH password login removes password guessing altogether.

Uninstalling removes fail2ban and its panel-managed configuration.
