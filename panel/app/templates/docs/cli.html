The lite-panel command

The installer adds a global lite-panel command (/usr/local/bin/lite-panel). Run it with sudo on the server.

CommandPurpose
sudo lite-panel reset-password --username adminResets the admin password to a generated 24-character one and signs out all sessions.
sudo lite-panel reset-password --username admin --password "…"Sets a specific password (at least 12 characters).
sudo lite-panel rebuildRe-renders every panel-managed config file from the database. Same as Rebuild on the Stack page.
sudo lite-panel generate-password --length 24Prints a random password.
lite-panel create-admin --username NAMECreates an administrator account.
lite-panel init-dbCreates any missing database tables.

Services

ServiceWhat it is
lite-panelThe panel (uvicorn on 127.0.0.1:8765).
lite-panel-adminerThe Adminer PHP server on 127.0.0.1:8766.
nginxServes the panel on port 8443 and all your websites on 80/443.
lite-panel-app-<site>One per Node.js / Python site.
sudo systemctl status lite-panel            # state
sudo systemctl restart lite-panel           # restart after a config change
sudo journalctl -u lite-panel -f            # live panel logs
sudo journalctl -u lite-panel-adminer -f    # Adminer logs
sudo journalctl -u lite-panel-app-shop -f   # one application's logs

Where things live

PathContents
/opt/lite-panelThe panel's code and Python virtualenv.
/etc/lite-panel/panel.envSecret key and path settings.
/etc/lite-panel/apps/Root-only environment files for application sites.
/var/lib/lite-panel/panel.dbThe panel's SQLite database (sites, jobs, schedules, settings).
/var/log/lite-panel/The panel's own logs.
/var/www/<site>Each site's files.
/var/backups/lite-panel/<site>Backup archives.
/etc/nginx/sites-available/Panel-generated virtual hosts (lite-panel-*).
/etc/nginx/custom/Your per-site nginx overrides.
/etc/systemd/system/lite-panel-app-*.serviceApplication services.
Back up the panel's own dataThe SQLite database at /var/lib/lite-panel/panel.db is the source of truth for the panel's configuration. Include it, with /etc/lite-panel, in any server-level backup; Rebuild can then recreate every generated file.
