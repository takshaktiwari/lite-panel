Updating the panel

The Setup page shows the version you are running and checks GitHub for newer releases. When one is available a banner appears at the top of every page. Click View & Update, review the release notes, and confirm. The panel downloads the release and restarts itself; sites keep running during the update.

Take a quick backup of important sites, and keep a copy of /var/lib/lite-panel/panel.db, before major version updates.

Re-running the installer

The installer is idempotent. To repair a broken install:

sudo bash /opt/lite-panel/install.sh

To start the panel's own install from scratch:

sudo bash /opt/lite-panel/install.sh --force-reinstall

Uninstalling

sudo bash /opt/lite-panel/uninstall.sh

This removes the panel, its services and its nginx site. Your websites' files, databases and installed packages are left alone. Review what the uninstaller offers about site files before using any option that deletes data, and keep backups.
