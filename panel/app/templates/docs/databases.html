Setup

Databases use MariaDB. Install it once from Stack (or in the Setup wizard); it also installs Adminer, the browser-based database tool. The panel talks to MariaDB over its local unix socket, so the database is never exposed to the internet.

Creating a database

  1. Open Databases and choose Create database.
  2. Enter a name, and optionally link it to a site (it then appears on that site's page and in its backups).
  3. Choose the database user: Create new user (a strong password is suggested) or Select existing user to give another user access.
  4. Submit. The database and user are created and granted privileges.
The password is shown once Passwords are never stored. Copy it into your application's configuration immediately. If you lose it, set a new one with Change password.

In your application use host localhost (or 127.0.0.1), the database name and the user you created.

Managing databases and users

ActionMeaning
Open in AdminerBrowse tables and rows, run queries, edit data. Adminer is only reachable while you are logged in to the panel and always connects to this server's MariaDB.
ExportDownloads a compressed SQL dump (.sql.gz) made with mysqldump.
ImportUploads a .sql or .sql.gz file into the database. Large files are uploaded in chunks and imported as a background job.
Change passwordSets a new password for the database user.
Assign / change userMoves the database to a different (new or existing) user.
DeleteDrops the database and its user. Cannot be undone.

Databases that exist in MariaDB but were not created through the panel are listed separately so you can see them.

Common tasks

Move a site from another host

  1. Create the database and user here.
  2. Import the .sql or .sql.gz dump from the old host.
  3. Update the app's configuration (e.g. .env or wp-config.php) with the new credentials.

Use a database from outside the server

Port 3306 is closed by design. Prefer an SSH tunnel; if you must open it, allow only your client's IP on the Firewall page.
