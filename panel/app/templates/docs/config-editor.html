What it edits

The Config editor lets you change a small, safe set of server files in the browser:

FileTypical reasons
php.ini for each installed PHP version (FPM)Raise upload_max_filesize, post_max_size, memory_limit, max_execution_time.
nginx.conf (global nginx)Server-wide nginx settings.
Per-site nginx overrideRewrites, extra headers, caching rules, redirects for one site. The panel never overwrites this file.

How saving works

Saving is designed so a typo cannot take the server down:

  1. The current file is backed up first (the last 5 backups are kept).
  2. Your change is validated (nginx's own config test, PHP's own check) before it is applied.
  3. The service is reloaded.
  4. If validation or the reload fails, the backup is restored automatically and you see the error.

Examples

Allow bigger uploads in PHP

Config → PHP → set upload_max_filesize = 64M and post_max_size = 64M. Also check the site's upload limit (nginx client_max_body_size defaults to 128 MB).

Redirect an old URL (per-site override)

rewrite ^/old-page$ /new-page permanent;

Add a header

add_header X-My-Header "value" always;
Anything the panel generates itself (virtual hosts, PHP pools, services) is overwritten by Rebuild. Put your own nginx changes in the per-site override file; it is the one place that is always preserved.
