What it can reach

The file manager works inside /var/www, where all sites live. It cannot go outside that folder, so it cannot be used to browse the rest of the server (use the terminal for that). Sites you open from the Sites list land in their own folder.

Browsing

Click a folder to open it; the breadcrumb at the top jumps back up. Select several rows with the checkboxes to act on many items at once. Folder sizes are calculated on demand so large trees do not slow the page.

Actions

ActionNotes
New folder / new fileCreate items in the current folder.
UploadDrag and drop or choose files. Uploads are sent in chunks with a progress bar, up to 1 GB per file. If a file already exists you are asked whether to replace it.
DownloadDownload any file from its row menu. To download a folder, archive it first and download the zip.
View / editOpens text files in a code editor with syntax highlighting. Files up to 1 MB are editable; larger files can be viewed in part.
Rename / duplicate / move / copyAvailable per item and for a selection (move and copy ask for the destination folder).
Archive / extractCreate a zip from files or folders (up to 1 GB of source data) and extract zips in place. Extracting runs as a job with a progress bar.
Permissions (chmod)Set a mode such as 644 for files or 755 for folders, for one item, a selection, or recursively.
DeleteSingle or bulk; asks for confirmation. Not recoverable.

Ownership and permissions

Each site's files belong to its own system user, so the website runs with the right access. Files you upload through the panel are owned for that site. If an application reports "permission denied" writing to a folder (for example storage or uploads), give that folder write permission such as 775 recursively, rather than 777.

Tips

  • Upload a project as a zip and extract it, instead of uploading thousands of small files.
  • To work as the site user on the command line, use the site's Terminal button or pick the site in the Terminal page.
  • Edit configuration files for nginx or PHP in the Config editor, not here; it validates the change first.
