Everything lite-panel can do, how each part works, and how to set it up. New here? Start with Installation and the Quick start.

What lite-panel is A small, self-hosted control panel for an Ubuntu or Debian server. It manages websites (PHP, static, Node.js and Python), databases, SSL certificates, FTP, backups, cron jobs, the firewall and more, from one web page. Everything it does is a plain, visible change to the server, and you can always do the same thing by hand over SSH.
