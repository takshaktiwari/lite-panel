What it does

The Firewall page manages UFW (Uncomplicated Firewall), the standard firewall on Ubuntu and Debian. A firewall decides which network ports on the server are reachable from the internet. If UFW is not installed the page tells you; install it with sudo apt install ufw.

Two firewalls Cloud providers (AWS security groups, Google Cloud VPC rules, DigitalOcean cloud firewalls…) have their own firewall in front of the server. A port must be open in both to be reachable. A "closed port" that you opened in the panel but cannot reach is usually blocked there.

Enabling and disabling

The toggle turns UFW on or off. While it is off the rules are saved but not enforced. When you turn it on the panel makes sure SSH is allowed first so you cannot lock yourself out of the server. (This safeguard covers the standard SSH port 22. If you run SSH on a different port, add a rule for it yourself before enabling the firewall.)

Default policy

  • Deny incoming (recommended): everything not explicitly allowed is blocked. SSH (port 22) is allowed automatically first if it is not already.
  • Allow incoming: every port is open unless denied. Only use for troubleshooting.

Outgoing traffic is allowed by default so the server can reach package repositories and APIs.

Common ports

The page lists the ports a typical server needs, with a one-click Add rule:

PortServiceWhen to open
22/tcpSSHAlways (remote administration, and the web terminal's alternative).
80/tcpHTTPWebsites, and Let's Encrypt validation.
443/tcpHTTPSWebsites over TLS.
8443/tcpLite-panelThe panel itself. Prefer allowing it only from your own IP.
21/tcp and 30000–30100/tcpFTP and its passive data portsOnly if you use FTP.

Adding a rule

FieldMeaning
PortA port (8443) or range (30000:30100).
ProtocolTCP, UDP or both.
FromLeave as Anywhere, or enter an IP / network (for example your office IP) to restrict who can connect.
ActionAllow, Deny, or Limit (allow but rate-limit repeated connections, good for SSH).
CommentA note for your future self.

The Active rules table lists everything in UFW; delete a rule from its row.

Ports that should stay closed

  • 3306 (MariaDB): the panel uses a local socket. If you need remote access, allow only specific client IPs.
  • 8765 / 8766 (panel daemon and Adminer): bound to localhost; nginx proxies to them.
  • 6379 / 11211 (Redis, Memcached): internal services; never expose them.
  • Ports used by your Node.js / Python apps (3001 …): only nginx talks to them locally; do not open them.
