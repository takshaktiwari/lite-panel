This walkthrough takes a fresh server to a live website. Each step links to the page that explains it in full.

1. Run the setup wizard

The Setup page detects your OS and RAM and installs what a typical site needs:

  • PHP — tick the versions you want. Only versions that can really be installed on this machine are listed. See Stack → PHP for why you may see just one.
  • MariaDB (databases, with Adminer), SSL (Let's Encrypt via certbot) and FTP (vsftpd) — optional, tick what you need. Each can also be added later from the Stack page.

Click Set up server. A job runs with a live log. PHP-FPM worker counts, OPcache and MariaDB memory are sized automatically from the server's RAM.

2. Point your domain at the server

At your domain registrar or DNS host, create an A record for the domain (and www) pointing at the server's public IP. DNS can take minutes to hours to spread. The site page has a Check DNS propagation button that tests it from several public resolvers.

3. Create the site

Go to Sites → New site, enter the domain, choose the site type (PHP / static, Node.js or Python) and click Create site. See Sites and Node.js & Python apps.

4. Upload your code

Use the file manager, FTP, or the terminal (for example git clone) to put the project in the site's folder, /var/www/<site>.

5. Database (if the app needs one)

On Databases, create a database and user and link it to the site. The password is shown once; copy it into your app's configuration. See Databases.

6. Turn on HTTPS

Once DNS points here, open the site and click Enable HTTPS. A free Let's Encrypt certificate is issued and renews automatically.

7. Protect the server

  • Turn on the Firewall and allow only the ports you need.
  • Install Fail2ban to stop SSH brute-force attempts.
  • Set up scheduled backups.
Common recipes
  • Laravel / WordPress: PHP site; point the document path at public for Laravel. See Document path.
  • React / Vue / static build: a PHP/static site with PHP set to None; upload the built dist or build folder contents.
  • Next.js, Express, NestJS: a Node.js site. Flask, Django, FastAPI: a Python site. See Node.js & Python apps.
