Setup

Install FTP (vsftpd) from Stack or the Setup wizard. Then open these ports in your cloud firewall and in the panel's Firewall:

  • TCP 21 (FTP control)
  • TCP 30000–30100 (passive data connections)
Plain FTP is not encrypted. For sensitive work prefer SFTP with SSH keys, and use FTP only when a tool requires it.

Two kinds of account

KindDescription
Linked to a siteIf the path you choose is a site's own folder, the login is that site's system user (site_<name>) with a password. File ownership is already correct, so nothing needs adjusting. A site has at most one.
StandaloneFor any other folder (for example a subfolder or an unrelated directory). A dedicated system user is created that owns that folder, and you choose its username.

Creating an account

  1. Open FTP and click Create FTP account.
  2. Pick the path (a site's folder, or type a custom path under the sites root).
  3. For a custom path, enter a username. For a site folder the username is filled in for you.
  4. Set a password and submit. Connect with host = your server's IP, the shown username, and the password.

The account is jailed to its folder: it cannot see anything above it.

Managing accounts

  • Change password — sets a new one.
  • Delete — removes the login. The folder and its files are never touched.

The site page also has an FTP section that links here for that site.
