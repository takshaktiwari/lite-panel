Requirements

  • OS: Ubuntu 20.04 / 22.04 / 24.04 (or newer) or Debian 11 / 12.
  • Server: a fresh VPS with root or sudo access. 1 GB RAM is recommended; 512 MB works because the installer adds a swap file automatically on very small servers.
  • Network: ports 80 and 443 for your websites, and 8443 for the panel itself, must be reachable (see Network access).

Install

Run one command as root (or with sudo) on the server:

curl -fsSL https://raw.githubusercontent.com/takshaktiwari/lite-panel/main/install.sh | sudo bash

The installer is safe to run again; every step checks whether it is already done and skips itself. It will:

  1. Check that the OS is Ubuntu or Debian.
  2. Install base packages: nginx, python3-venv, php-cli, openssl, git and curl.
  3. Add a 1 GB swap file if the server has 512 MB RAM or less and no swap.
  4. Clone the panel to /opt/lite-panel and create its Python virtualenv.
  5. Generate a random secret key and write /etc/lite-panel/panel.env.
  6. Create a self-signed TLS certificate (valid 10 years) so the panel is HTTPS from the first minute.
  7. Write and enable the panel's nginx site.
  8. Install and start two systemd services: lite-panel (the panel) and lite-panel-adminer (the database browser).
  9. Create the SQLite database and an admin account with a random password.
  10. Run a health check and print the login details.

When it finishes it prints a box like this. Copy the password now; it is shown once.

Panel URL  : https://<server-address>:8443/
Username   : admin
Password   : <random-generated>
The address printed may be a private one On cloud servers (AWS, for example) the installer can print the server's private address (such as 172.31.x.x), which only works from inside the cloud network. Use the server's public IP instead: https://PUBLIC-IP:8443/.

Network access

The panel listens on port 8443. Two things can stop you reaching it, and neither is a panel fault:

  1. Cloud firewall / security group. On AWS, Google Cloud, Azure, DigitalOcean and similar providers, inbound ports are closed by default. Add inbound rules for TCP 8443 (restrict to your own IP for safety), 80 and 443. This is the most common reason a fresh install "doesn't work".
  2. Server firewall (UFW). If UFW is active on the server, allow the same ports from the Firewall page or with sudo ufw allow 8443/tcp.

The browser certificate warning

Until you have a domain, the panel uses a self-signed certificate, so the browser shows a warning. This is expected. Choose Advanced → Proceed. The connection is still encrypted. A domain is not needed to use the panel, only to put real certificates on your websites (see Sites → HTTPS).

Logging in

Sign in with the admin account. After five failed attempts the login is locked for 15 minutes. Sessions last 12 hours. There is a single administrator account.

  • Change the password: click the gear icon at the bottom of the sidebar → Change password.
  • Lost the password: run sudo lite-panel reset-password --username admin on the server. See Command line.
  • Dark mode: the moon icon next to your name toggles the theme.
