What swap is

Swap is disk space the operating system can use as overflow memory. When RAM fills up, the kernel moves rarely-used data to swap instead of killing a process. It is much slower than RAM, so it is insurance, not extra memory: it keeps MariaDB or PHP alive during a short spike (a large import, a build, a backup) rather than letting the kernel's out-of-memory killer stop them.

The Dashboard shows Swap: None when none is configured. The Swap page in the sidebar lets you set it up at any time.

Do you need it?

Server RAMRecommendation
512 MB or lessEssential. The installer adds 1 GB automatically.
1–2 GBStrongly recommended (2 GB).
4 GB and upOptional safety net; 2 GB is plenty.

The installer only adds swap on very small servers, which is why a larger server shows "None" until you add it here. The recommended size on the page is calculated from the server's RAM (capped at 2 GB).

Setting it up

  1. Open Swap.
  2. Choose a size. Sizes that would not leave 1 GB of free disk are disabled.
  3. Click Create swap. A job creates /swapfile, formats it, turns it on and adds it to /etc/fstab so it comes back after a reboot.

The page then shows the new size, and the Dashboard's Swap card switches from "None" to a usage meter.

Resizing and removing

  • Resize: pick a new size and click Resize. The old file is switched off (anything in it moves back to RAM first), replaced, and switched on again.
  • Remove: Remove swap file turns it off, deletes the file and removes the /etc/fstab entry.
Resizing or removing needs free RAMTurning swap off moves its contents back into memory. If swap is heavily used and RAM is nearly full, the job fails with an error and nothing is changed; try again when the server is quieter.

What the panel manages

Only the single /swapfile it creates. If the server already has other swap (a swap partition, or a file you made by hand) it is listed on the page but never touched, and the panel's file is added alongside it.

Swappiness

Swappiness (0–100) tells the kernel how eagerly to use swap. The Linux default is 60. On a web server it is usually better to keep data in RAM and use swap only when needed, so 10 is a common choice. Lower values use swap later; higher values use it sooner. Saving applies immediately and persists across reboots (/etc/sysctl.d/99-lite-panel-swap.conf).

Troubleshooting

  • "Swap can't be managed": the page needs a Linux server with swapon and mkswap.
  • Creation fails on a container or some VPS types: some container platforms (LXC/OpenVZ) do not allow swap from inside the guest. Ask the provider, or enable swap in the host settings.
  • "Not enough free disk": free some space (see Monitor → disk breakdown) or choose a smaller size.

By hand (without the panel)

sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
