What the Stack is

The Stack page lists every component the panel can install, and lets you install or remove each independently. Nothing is fixed at install time: the panel asks the server's package manager what is really available and offers only that. The panel's own Python runtime is installed by the installer and is not managed here.

PHP versions

Tick the versions to install; every version appears as an option on the New site form and the site page. Each version has a manage page for extensions (add or remove modules such as gd, imagick, redis). Core modules the panel needs cannot be removed.

"I only see one PHP version"

Ubuntu and Debian ship only one PHP version themselves. More versions come from a third-party repository (ondrej/php on Ubuntu, Sury on Debian). The page shows an Add PHP repository button when your OS release is supported, and one click unlocks the older and newer versions.

Brand-new OS releases A just-released Ubuntu or Debian version often has no build in that repository yet (for example Ubuntu 26.04 at the time of writing). The panel detects this and tells you; only the version bundled with the OS can be installed. This is not something the panel can fix. Use Ubuntu 24.04 / 22.04 or Debian 12 to get several versions side by side, or wait for the repository to add your release; the panel re-checks every time.

Node.js

Node.js comes from NodeSource and only one major version runs system-wide at a time. Choosing a different major switches the whole server to it, so every Node.js site then uses that version. Pick the major your apps need (for example 20 or 22).

Installing and removing

Each install or removal runs as a job with a live log. Removing a component does not delete your sites or databases, but sites that depend on it will stop working until it is installed again.

Rebuild configuration

Rebuild regenerates every panel-managed config file (nginx virtual hosts, PHP pools, application services, Fail2ban settings) from the panel's database. Use it after restoring a backup of the panel, after resizing the server (tuning is recalculated from RAM), or if a config file was changed by hand and you want the panel's version back. The same is available as sudo lite-panel rebuild.
