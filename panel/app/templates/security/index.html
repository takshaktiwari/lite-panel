About Security Scanners:
  • LMD (Linux Malware Detect): Scans website files under /var/www for PHP web shells, backdoors, and injected malware. Flagged files can be quarantined (recoverable) or deleted.
  • rkhunter: Checks system binaries, hidden processes, and OS-level rootkits. Run periodically as a security audit.
  • Neither tool runs continuous background daemons, keeping memory and CPU usage at 0% when idle.
