Generate SSH key pair

Creates a new key pair, registers the public key on this server, and immediately downloads the private .pem file.

{{ ui.csrf(session) }}
When to use Generate: Use this if you want Lite-Panel to create a brand-new SSH key pair for you.
  • How it works: The server keeps the public key and automatically initiates a one-time download of the private .pem file to your browser.
  • How to connect: Save the downloaded .pem key locally, run chmod 600 key.pem, then connect using ssh -i key.pem user@{{ public_ip }}.

Import existing public key

Paste an existing OpenSSH public key (from your computer's ~/.ssh/id_ed25519.pub or similar).

{{ ui.csrf(session) }}
When to use Import: Use this if you or a team member already have an existing SSH key pair on your computer.
  • How it works: You only paste your public key (e.g. cat ~/.ssh/id_ed25519.pub). Your private key never leaves your computer.
  • How to connect: Connect directly from your computer terminal without extra parameters: ssh user@{{ public_ip }}.
